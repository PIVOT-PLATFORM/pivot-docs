# US31.1.6 — Approche 'tout est projet'

**En tant que** PMO
**Je veux** suivre de façon unifiée les projets, la maintenance et les activités récurrentes
**Afin de** disposer d'une vision complète de l'allocation et fiabiliser la capacité à faire (cf. US31.1.3)

> ⚠️ **Hors v2 adaptative** — non repris dans la mise à jour du backlog PPM v2 ; conservé pour mémoire, à confirmer.

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given des projets, de la maintenance et des activités récurrentes, when le PMO consulte l'allocation, then les trois natures apparaissent dans une vue unifiée | ⬜ |
| L'allocation de ressources agrège projets, maintenance et récurrent pour le calcul de capacité | ⬜ |
| Error : given une activité récurrente sans nature définie, system la signale comme non catégorisée | ⬜ |
| Security/Gouvernance : la visibilité de l'allocation respecte les périmètres par rôle | ⬜ |
