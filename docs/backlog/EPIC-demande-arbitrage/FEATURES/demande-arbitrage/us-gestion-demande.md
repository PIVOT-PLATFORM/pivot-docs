# US31.1.1 — Gestion de la demande

**En tant que** PMO
**Je veux** recueillir les demandes et idées via des formulaires typés, les qualifier et les faire suivre un circuit de validation
**Afin de** tracer la frontière PPM/outil de tâches et instruire les demandes avant tout lancement

> ⚠️ **Hors v2 adaptative** — non repris dans la mise à jour du backlog PPM v2 ; conservé pour mémoire, à confirmer.

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un demandeur, when il soumet un formulaire typé de demande, then la demande est enregistrée avec son type et son statut initial | ⬜ |
| Chaque demande passe par une étape de qualification puis un circuit de validation configurable | ⬜ |
| Error : given un formulaire incomplet, system bloque la soumission et signale les champs requis manquants | ⬜ |
| Security/Gouvernance : chaque changement d'état de la demande est horodaté et attribué à son auteur (traçabilité) | ⬜ |
| A11y : formulaires de demande conformes RGAA 4 / WCAG 2.1 AA (navigation clavier, libellés) | ⬜ |
