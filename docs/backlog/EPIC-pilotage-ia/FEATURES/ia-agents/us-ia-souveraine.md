# US34.1.4 — IA souveraine

**En tant que** DSI
**Je veux** des traitements IA hébergés en France/UE avec des modèles maîtrisés, positionnés 'souverain, fiable, transparent'
**Afin de** garantir la souveraineté des traitements IA pour les portefeuilles sensibles

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une fonction IA, when elle est exécutée, then les traitements sont hébergés en France/UE avec des modèles maîtrisés documentés | ⬜ |
| Le positionnement 'souverain, fiable, transparent' est attesté et vérifiable | ⬜ |
| Error : given l'indisponibilité du modèle souverain, system n'utilise pas de repli non souverain sans consentement | ⬜ |
| Security/Gouvernance : non-réutilisation des données pour l'entraînement contractualisée ; traitements tracés | ⬜ |
