# US29.6.1 — Approbations humaines

**En tant que** opérateur
**Je veux** insérer des étapes d'approbation/revue bloquantes, assignables et multi-canaux (messagerie, e-mail, mobile) avec historique
**Afin de** sécuriser les processus à enjeu par une validation humaine

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une étape d'approbation, when le workflow l'atteint, then il se met en pause jusqu'à décision de l'assigné | ⬜ |
| Given une demande d'approbation, when elle est envoyée, then l'assigné peut décider via messagerie, e-mail ou mobile | ⬜ |
| Security/Gouvernance : chaque décision d'approbation est horodatée et attribuée dans l'historique | ⬜ |
