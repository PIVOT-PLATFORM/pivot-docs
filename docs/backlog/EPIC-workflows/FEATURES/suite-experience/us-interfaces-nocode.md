# US29.9.2 — Interfaces no-code

**En tant que** maker
**Je veux** créer des formulaires, pages et mini-apps déclenchant les workflows, non facturés à l'usage
**Afin de** exposer des interfaces métier sans surcoût d'usage

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un formulaire/mini-app, when un utilisateur le soumet, then le workflow associé se déclenche | ⬜ |
| Given ces interfaces, when elles sont utilisées, then elles ne sont pas facturées à l'usage | ⬜ |
| A11y : les formulaires et pages générés respectent RGAA 4 / WCAG 2.1 AA | ⬜ |
