# US29.9.1 — Applications mobiles

**En tant que** utilisateur métier
**Je veux** recevoir notifications, traiter approbations et suivre les runs sur mobile
**Afin de** agir sur mes workflows en mobilité

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given l'app mobile, when une approbation m'est assignée, then je reçois une notification et peux décider depuis le mobile | ⬜ |
| Given un run en cours, when je l'ouvre sur mobile, then je vois son statut | ⬜ |
| A11y : l'app mobile respecte les critères d'accessibilité (contraste, tailles, lecteur d'écran) | ⬜ |
