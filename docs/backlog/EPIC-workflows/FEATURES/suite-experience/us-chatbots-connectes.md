# US29.9.4 — Chatbots connectés

**En tant que** administrateur
**Je veux** brancher des chatbots aux workflows, désactivables par l'administrateur
**Afin de** offrir une interface conversationnelle contrôlée

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un chatbot branché à un workflow, when un utilisateur discute, then le workflow est déclenché avec le contexte | ⬜ |
| Given un chatbot, when l'administrateur le désactive, then il n'est plus accessible | ⬜ |
| Security/Gouvernance : le périmètre d'actions du chatbot est contrôlé par l'administrateur | ⬜ |
