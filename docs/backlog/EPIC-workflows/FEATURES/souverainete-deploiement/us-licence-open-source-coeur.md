# US29.8.3 — Licence open source du cœur

**En tant que** DSI
**Je veux** disposer d'un cœur sous licence permissive (MIT) offrant auditabilité, extension et réversibilité maximales
**Afin de** auditer, étendre et pérenniser la solution

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cœur du produit, when j'en consulte la licence, then elle est permissive (MIT) | ⬜ |
| Given le code source, when je l'audite ou l'étends, then aucune restriction de licence ne l'empêche | ⬜ |
