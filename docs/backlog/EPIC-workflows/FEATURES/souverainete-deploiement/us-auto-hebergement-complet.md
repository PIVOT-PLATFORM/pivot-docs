# US29.8.1 — Auto-hébergement complet

**En tant que** DSI
**Je veux** déployer la solution en self-host Docker/Kubernetes documenté, y compris air-gap, avec données 100 % dans le périmètre de l'organisation
**Afin de** atteindre la classe A de souveraineté pour les données sensibles

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given la documentation self-host, when je déploie via Docker/Kubernetes, then l'instance fonctionne dans mon périmètre | ⬜ |
| Given un environnement air-gap, when je déploie, then aucune dépendance sortante non documentée n'est requise | ⬜ |
| Security/Gouvernance : aucune donnée ne quitte le périmètre de l'organisation en auto-hébergement | ⬜ |
