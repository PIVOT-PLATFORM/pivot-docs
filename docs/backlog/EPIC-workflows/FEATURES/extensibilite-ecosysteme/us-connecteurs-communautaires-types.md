# US29.11.2 — Connecteurs communautaires typés

**En tant que** développeur
**Je veux** créer des connecteurs via un framework ouvert (paquets typés, hot reloading) avec contributions communautaires majoritaires
**Afin de** étendre le catalogue rapidement grâce à la communauté

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le framework de connecteurs, when je développe un paquet typé, then je bénéficie du hot reloading en développement | ⬜ |
| Given un connecteur communautaire, when il est publié, then il est installable dans le catalogue | ⬜ |
| Security/Gouvernance : les connecteurs tiers sont soumis à une revue/validation avant diffusion | ⬜ |
