# US29.11.5 — Embed OEM marque blanche

**En tant que** développeur
**Je veux** intégrer le builder dans un produit tiers via un SDK (provisionnement JWT, personnalisation)
**Afin de** offrir l'automatisation en marque blanche dans un produit tiers

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le SDK d'intégration, when je l'embarque dans mon produit, then le builder s'affiche personnalisé aux couleurs du produit | ⬜ |
| Given un utilisateur, when il est provisionné via JWT, then il accède au builder embarqué sans compte séparé | ⬜ |
| Security/Gouvernance : le provisionnement JWT isole les données de chaque tenant | ⬜ |
