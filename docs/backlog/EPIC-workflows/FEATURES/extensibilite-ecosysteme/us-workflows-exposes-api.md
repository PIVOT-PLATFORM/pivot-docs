# US29.11.3 — Workflows exposés en API

**En tant que** développeur
**Je veux** publier un workflow comme endpoint API sécurisé, le workflow devenant un service
**Afin de** réutiliser un workflow comme service applicatif

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow, when je le publie en API, then un endpoint sécurisé l'invoque et retourne son résultat | ⬜ |
| Given l'endpoint, when un client authentifié l'appelle, then le workflow s'exécute avec la charge fournie | ⬜ |
| Security/Gouvernance : l'endpoint requiert une authentification et applique un contrôle d'accès | ⬜ |
