# US29.11.1 — Serveur MCP

**En tant que** administrateur
**Je veux** exposer les actions/workflows comme outils MCP aux assistants IA externes, avec contrôle du périmètre exposé
**Afin de** interopérer avec les assistants IA selon le nouveau standard MCP

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow/action, when je l'expose via MCP, then il devient un outil invocable par un assistant IA externe | ⬜ |
| Given le serveur MCP, when l'administrateur définit le périmètre, then seuls les outils autorisés sont exposés | ⬜ |
| Security/Gouvernance : l'accès aux outils MCP est authentifié et journalisé | ⬜ |
