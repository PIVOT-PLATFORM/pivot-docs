# US29.11.4 — Partage communautaire

**En tant que** maker
**Je veux** publier et activer en un clic des workflows communautaires, avec collections éditorialisées
**Afin de** capitaliser sur les workflows partagés par la communauté

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow communautaire, when je l'active, then il est instancié en un clic dans mon espace | ⬜ |
| Given les collections éditorialisées, when je les parcours, then je trouve des workflows par thème | ⬜ |
| Security/Gouvernance : un workflow importé n'accède à aucun credential sans configuration explicite | ⬜ |
