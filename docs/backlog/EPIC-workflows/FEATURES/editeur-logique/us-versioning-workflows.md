# US29.1.7 — Versioning des workflows

**En tant que** maker
**Je veux** gérer des versions avec diff visuel et retour arrière, avec intégration Git souhaitée
**Afin de** tracer les évolutions et revenir à un état stable en cas de problème

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow modifié, when j'enregistre, then une nouvelle version est créée et consultable en diff visuel | ⬜ |
| Given une version antérieure, when je demande un retour arrière, then le workflow retrouve cet état | ⬜ |
| Security/Gouvernance : l'historique des versions est horodaté et attribué à un auteur | ⬜ |
