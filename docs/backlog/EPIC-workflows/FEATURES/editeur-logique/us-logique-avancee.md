# US29.1.4 — Logique avancée

**En tant que** maker
**Je veux** utiliser branches conditionnelles, boucles, fusion de branches, filtres et transformation de données
**Afin de** modéliser des processus professionnels au-delà des cas simples

| Critère | 🤖 Dev |

| Given un workflow, when j'ajoute une branche conditionnelle, then l'exécution suit la branche dont la condition est vraie | ⬜ |
| Given une boucle sur une collection, when elle s'exécute, then chaque élément est traité et les branches peuvent être fusionnées | ⬜ |
| Error : given une expression de filtre invalide, system bloque l'activation et signale l'erreur | ⬜ |
