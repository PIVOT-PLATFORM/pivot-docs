# US29.1.3 — Bibliothèque de modèles

**En tant que** utilisateur métier
**Je veux** activer en un clic des modèles de workflows prêts à l'emploi par cas d'usage
**Afin de** démarrer rapidement sans partir d'une page blanche

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given la bibliothèque de modèles, when je choisis un modèle par cas d'usage, then il est instancié en un clic dans mon espace | ⬜ |
| Given un modèle activé, when je l'ouvre, then je peux l'adapter avant activation | ⬜ |
| Error : given un modèle nécessitant un connecteur non configuré, system signale les prérequis manquants | ⬜ |
