# US29.1.2 — Constructeur visuel no-code

**En tant que** utilisateur métier
**Je veux** construire un workflow par glisser-déposer sans compétence technique, avec test pas à pas
**Afin de** autonomiser les équipes métier dans l'automatisation

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given l'éditeur ouvert, when je glisse-dépose des étapes sur le canvas, then le workflow se construit visuellement | ⬜ |
| Given un workflow construit, when je lance le test pas à pas, then chaque étape s'exécute et affiche ses données intermédiaires | ⬜ |
| A11y : le constructeur est navigable au clavier et compatible lecteur d'écran (RGAA 4 / WCAG 2.1 AA) | ⬜ |
