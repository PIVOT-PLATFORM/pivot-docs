# US29.1.5 — Étapes de code

**En tant que** développeur
**Je veux** insérer du code JavaScript/Python/TypeScript librement mixé aux étapes visuelles
**Afin de** couvrir les cas non pris en charge par les étapes standard

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow, when j'ajoute une étape de code, then je peux écrire du JS/Python/TS accédant aux données du workflow | ⬜ |
| Given une étape de code, when elle retourne une valeur, then celle-ci est disponible pour les étapes suivantes | ⬜ |
| Security/Gouvernance : le code s'exécute dans un environnement isolé (sandbox) sans accès non autorisé à l'hôte | ⬜ |
