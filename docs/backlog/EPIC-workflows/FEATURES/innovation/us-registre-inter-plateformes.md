# US21.13.2 — Registre inter-plateformes

**En tant que** DSI
**Je veux** tenir un inventaire unifié des automatisations tous outils confondus (propriétaires, credentials, dépendances, criticité)
**Afin de** disposer d'une 'CMDB de l'automatisation'

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given plusieurs outils d'automatisation, when je consulte le registre, then toutes les automatisations sont inventoriées avec propriétaire et criticité | ⬜ |
| Given une automatisation, when je l'ouvre, then ses credentials et dépendances sont recensés | ⬜ |
| Security/Gouvernance : le registre signale les automatisations sans propriétaire (orphelines) | ⬜ |
