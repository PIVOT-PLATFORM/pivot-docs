# US29.7.8 — Analytique IA unifiée

**En tant que** DSI
**Je veux** disposer d'une couche type Gumstack, source de vérité de toute l'activité IA (usage, flux de données, coûts) à l'échelle de l'organisation
**Afin de** piloter l'activité IA de façon consolidée

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given l'activité IA de l'organisation, when je consulte la couche analytique, then usage, flux de données et coûts sont consolidés | ⬜ |
| Given cette couche, when un nouvel appel IA a lieu, then il alimente la source de vérité unique | ⬜ |
| Security/Gouvernance : l'accès à l'analytique IA respecte le RBAC de l'organisation | ⬜ |
