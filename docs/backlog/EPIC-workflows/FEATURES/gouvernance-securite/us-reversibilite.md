# US21.7.7 — Réversibilité

**En tant que** DSI
**Je veux** exporter les workflows et l'historique de façon exploitable, attacher une documentation à chaque flux et disposer d'une procédure de sortie documentée
**Afin de** éviter le verrouillage fournisseur

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow, when je l'exporte, then l'export est exploitable (réimportable / lisible) avec son historique | ⬜ |
| Given un flux, when je le documente, then la documentation reste attachée au workflow | ⬜ |
| Security/Gouvernance : une procédure de sortie documentée permet de récupérer l'ensemble des actifs | ⬜ |
