# US29.2.2 — Planification

**En tant que** maker
**Je veux** programmer des exécutions (cron, intervalles) sans déclencheur externe
**Afin de** automatiser des tâches récurrentes de façon autonome

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow, when je définis une planification cron ou par intervalle, then il s'exécute automatiquement aux moments prévus | ⬜ |
| Given une planification active, when l'heure arrive, then une exécution est déclenchée et journalisée | ⬜ |
| Error : given une expression cron invalide, system refuse l'enregistrement et l'explique | ⬜ |
