# US29.2.4 — Scraping et navigateur

**En tant que** maker
**Je veux** extraire des données structurées depuis toute URL, automatiser un navigateur et utiliser une extension Chrome
**Afin de** capturer des données de sources sans API

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une URL, when je configure une extraction, then les données structurées ciblées sont récupérées | ⬜ |
| Given une automatisation de navigateur, when elle s'exécute, then les actions (clics, saisies, navigation) sont rejouées | ⬜ |
| Error : given une page dont la structure a changé, system signale l'échec d'extraction sans corrompre les données | ⬜ |
