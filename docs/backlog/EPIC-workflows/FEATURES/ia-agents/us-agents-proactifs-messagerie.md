# US29.5.12 — Agents proactifs en messagerie

**En tant que** utilisateur métier
**Je veux** déployer des agents dans Slack/Teams/e-mail, interpellables par mention, avec surveillance et actions contextuelles
**Afin de** obtenir de l'aide contextuelle directement dans mes outils de travail

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un agent déployé dans Slack/Teams/e-mail, when je le mentionne, then il répond et agit en contexte | ⬜ |
| Given une surveillance active, when un événement pertinent survient, then l'agent réagit proactivement | ⬜ |
| Security/Gouvernance : l'agent n'agit que dans le périmètre et les canaux autorisés | ⬜ |
