# US29.5.4 — Copilote de construction

**En tant que** utilisateur métier
**Je veux** générer un workflow à partir d'une description en langage naturel, avec révision humaine avant activation
**Afin de** accélérer la création de workflows

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une description en langage naturel, when je la soumets au copilote, then un brouillon de workflow est généré | ⬜ |
| Given un brouillon généré, when je le révise, then je peux le modifier avant activation | ⬜ |
| Security/Gouvernance : aucun workflow généré n'est activé sans validation humaine explicite | ⬜ |
