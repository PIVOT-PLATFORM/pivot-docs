# US29.5.2 — Agents IA outillés

**En tant que** maker
**Je veux** créer des agents (mission, prompt, outils, mémoire) insérables dans les workflows
**Afin de** déléguer des tâches complexes à un agent autonome outillé

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un agent défini avec mission/prompt/outils/mémoire, when il est inséré dans un workflow, then il exécute sa mission en appelant ses outils | ⬜ |
| Given un agent, when il utilise sa mémoire, then il conserve le contexte entre étapes | ⬜ |
| Security/Gouvernance : les outils accessibles à l'agent sont limités à un périmètre déclaré et journalisés | ⬜ |
