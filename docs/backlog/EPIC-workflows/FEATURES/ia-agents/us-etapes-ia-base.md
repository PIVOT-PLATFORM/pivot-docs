# US29.5.1 — Étapes IA de base

**En tant que** maker
**Je veux** ajouter des étapes appelant un LLM (résumé, classification, génération) dans un workflow
**Afin de** intégrer l'IA dans mes automatisations

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un workflow, when j'ajoute une étape IA (résumé/classification/génération), then le LLM traite l'entrée et retourne un résultat exploitable | ⬜ |
| Given une étape IA, when je configure le prompt, then il peut référencer les données des étapes précédentes | ⬜ |
| Security/Gouvernance : chaque appel IA est journalisé (modèle, workflow appelant) pour audit | ⬜ |
