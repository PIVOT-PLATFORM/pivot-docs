# US29.5.6 — Garanties de données IA

**En tant que** DSI
**Je veux** contractualiser le non-entraînement sur les données, le ZDR avec les fournisseurs de modèles et la localisation des traitements
**Afin de** protéger les données confiées aux modèles IA

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un fournisseur de modèle, when il est intégré, then les garanties ZDR / non-entraînement / localisation sont contractualisées et documentées | ⬜ |
| Given un traitement IA, when il s'exécute, then sa localisation respecte la politique définie | ⬜ |
| Security/Gouvernance : le non-entraînement sur les données de l'organisation est vérifiable | ⬜ |
