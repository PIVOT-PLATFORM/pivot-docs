# US29.5.9 — Multi-agents

**En tant que** maker
**Je veux** orchestrer plusieurs agents coordonnés (agents appelant workflows et autres agents)
**Afin de** traiter des tâches complexes par collaboration d'agents

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given plusieurs agents, when un agent en appelle un autre, then la coordination et le passage de contexte fonctionnent | ⬜ |
| Given une orchestration multi-agents, when elle s'exécute, then chaque agent respecte son périmètre | ⬜ |
| Security/Gouvernance : les interactions inter-agents sont journalisées pour audit | ⬜ |
