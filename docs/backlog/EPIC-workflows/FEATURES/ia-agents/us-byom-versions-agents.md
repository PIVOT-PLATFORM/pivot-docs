# US21.5.8 — BYOM et versions d'agents

**En tant que** administrateur
**Je veux** choisir le modèle (Bring Your Own Model), publier des versions d'agents et utiliser des templates d'agents
**Afin de** maîtriser les modèles utilisés et industrialiser les agents

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un agent, when je configure BYOM, then il utilise le modèle choisi par l'organisation | ⬜ |
| Given un agent, when je publie une version, then elle est identifiable et réutilisable via un template | ⬜ |
| Security/Gouvernance : le choix du modèle respecte les politiques de souveraineté définies | ⬜ |
