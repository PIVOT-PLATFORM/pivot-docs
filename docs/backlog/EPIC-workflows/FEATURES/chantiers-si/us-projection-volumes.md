# US29.14.2 — Projection des volumes

**En tant que** DSI/architecte
**Je veux** projeter les volumes d'exécution à 3 ans avant de choisir le modèle de facturation et simuler les scénarios (tâche/crédit/illimité/capacité)
**Afin de** prendre une décision d'architecture éclairée sur le modèle économique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given les usages attendus, when l'équipe SI projette les volumes à 3 ans, then une estimation chiffrée par scénario est produite | ⬜ |
| Given les scénarios tâche/crédit/illimité/capacité, when ils sont simulés, then le modèle le plus adapté est recommandé | ⬜ |
| Security/Gouvernance : les hypothèses de projection sont documentées et traçables | ⬜ |
