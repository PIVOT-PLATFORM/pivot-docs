# US29.12.1 — Offre gratuite d'appel

**En tant que** utilisateur métier
**Je veux** disposer d'un plan gratuit permanent réellement utilisable
**Afin de** adopter le produit sans que l'offre gratuite soit un entonnoir inutilisable (leçon IFTTT)

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le plan gratuit, when je l'utilise au quotidien, then il permet des cas d'usage réels et non purement démonstratifs | ⬜ |
| Given le plan gratuit, when j'atteins ses limites, then elles sont assez élevées pour rester utile | ⬜ |
| Error : given un dépassement de quota gratuit, system l'indique clairement sans casser les workflows existants | ⬜ |
