# US29.12.3 — Droits inclus dans la suite

**En tant que** administrateur
**Je veux** inclure les droits d'usage (connecteurs standard) dans les licences bureautiques si écosystème de suite
**Afin de** favoriser l'adoption sans friction

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une licence bureautique de la suite, when un utilisateur automatise avec des connecteurs standard, then aucun coût additionnel ne s'applique | ⬜ |
| Given un connecteur premium hors périmètre inclus, when il est utilisé, then l'utilisateur en est informé | ⬜ |
| Security/Gouvernance : le périmètre des droits inclus est gouverné par l'administrateur de la suite | ⬜ |
