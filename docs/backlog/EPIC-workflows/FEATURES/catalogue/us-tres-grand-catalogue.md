# US29.3.2 — Très grand catalogue

**En tant que** utilisateur métier
**Je veux** disposer d'un catalogue de 5 000+ applications avec profondeur (10+ triggers/actions sur les apps majeures) et actions personnalisées
**Afin de** couvrir la longue traîne des intégrations attendues

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le catalogue, when je recherche une application majeure, then elle expose 10+ triggers/actions | ⬜ |
| Given un besoin non couvert, when je crée une action personnalisée, then elle s'ajoute au catalogue | ⬜ |
| Error : given un connecteur déprécié, system le signale et propose une alternative | ⬜ |
