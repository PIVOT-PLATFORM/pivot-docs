# US29.3.1 — Catalogue d'intégrations

**En tant que** utilisateur métier
**Je veux** connecter des applications avec authentification gérée (OAuth, clés) en quelques clics
**Afin de** intégrer mes outils sans manipuler les détails techniques d'authentification

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le catalogue, when je choisis un connecteur, then je m'authentifie (OAuth/clé) en quelques clics et la connexion est réutilisable | ⬜ |
| Given un connecteur connecté, when je l'ajoute à un workflow, then ses triggers et actions sont disponibles | ⬜ |
| Security/Gouvernance : les jetons OAuth et clés sont stockés chiffrés et jamais exposés en clair dans l'UI | ⬜ |
