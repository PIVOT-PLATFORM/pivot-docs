# US38.8.3 — Hackathons & événements d'innovation

**En tant que** responsable innovation
**Je veux** organiser des **hackathons / événements d'innovation** (inscription, équipes, jury, prix)
**Afin de** mobiliser et accélérer la génération de prototypes

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un hackathon, when je l'organise, then inscription, constitution d'équipes, jury et remise de prix sont outillés | ⬜ |
| Given les livrables, when l'événement se clôt, then les projets prometteurs entrent dans l'entonnoir (F38.3) | ⬜ |
