# US42.8.1 — Auto-hébergement

**En tant que** DSI souveraine
**Je veux** Déploiement self-host (Docker) avec réponses illimitées, données dans le périmètre.
**Afin de** répondre au besoin « Auto-hébergement » de la suite Forms

## Critères d'acceptation

| Critère | 🤖 Dev |

| Le form-builder tourne en self-host, données jamais sorties du périmètre. | ⬜ |
| Security/Gouvernance : conforme à la doctrine PIVOT (SSO, RBAC, RGPD, traçabilité, souveraineté) | ⬜ |
