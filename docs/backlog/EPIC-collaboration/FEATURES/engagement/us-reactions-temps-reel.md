# US30.11.1 — Réactions temps réel

**En tant que** participant
**Je veux** ajouter des réactions temps réel (tampons, émojis, applaudissements) sur les objets et le canevas
**Afin de** donner un retour instantané et vivant pendant l'atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je réagis à un objet avec un émoji visible en temps réel, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Émojis | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
