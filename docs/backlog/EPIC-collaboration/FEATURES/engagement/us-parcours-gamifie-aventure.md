# US22.11.2 — Parcours gamifié (Aventure)

**En tant que** participant
**Je veux** proposer un parcours gamifié (Aventure) à étapes et challenges avec validation d'acquis
**Afin de** engager les apprenants dans un format ludique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un participant progresse dans un parcours gamifié et valide ses acquis, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Validation d'acquis — orienté formation | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
