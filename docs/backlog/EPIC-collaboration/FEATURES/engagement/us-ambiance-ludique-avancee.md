# US30.11.3 — Ambiance ludique avancée

**En tant que** participant
**Je veux** proposer une ambiance ludique avancée : tchat audio, musique partagée, curseurs expressifs et avatars personnalisés
**Afin de** rendre les ateliers plus vivants et conviviaux
