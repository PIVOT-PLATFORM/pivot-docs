# US22.3.8 — Séquençage d'atelier (Session)

**En tant que** facilitateur
**Je veux** séquencer un atelier en conteneur agençant plusieurs activités (board, quiz, sondage) piloté en direct
**Afin de** dérouler un atelier riche de bout en bout en direct

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'animateur enchaîne board, quiz et sondage dans une session pilotée, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Quiz | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
