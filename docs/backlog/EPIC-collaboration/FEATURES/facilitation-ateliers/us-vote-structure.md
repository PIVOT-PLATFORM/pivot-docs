# US30.3.1 — Vote structuré

**En tant que** facilitateur
**Je veux** organiser un vote structuré (dot voting) sur les objets, avec résultats agrégés et masquage pendant le vote
**Afin de** prioriser collectivement de façon équitable

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je lance un dot voting et masque les résultats pendant le vote, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Résultats agrégés | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
