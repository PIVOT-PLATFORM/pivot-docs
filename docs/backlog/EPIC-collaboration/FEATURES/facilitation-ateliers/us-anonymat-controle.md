# US30.3.5 — Anonymat contrôlé

**En tant que** facilitateur
**Je veux** piloter l'anonymat des contributions (nominatif, pseudonyme ou anonyme) en tant qu'animateur
**Afin de** libérer la parole selon le contexte de l'atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'animateur bascule les contributions en mode anonyme, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Piloté par l'animateur | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
