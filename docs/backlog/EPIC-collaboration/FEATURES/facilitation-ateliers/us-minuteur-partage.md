# US22.3.2 — Minuteur partagé

**En tant que** facilitateur
**Je veux** afficher un minuteur partagé visible par tous les participants
**Afin de** cadencer les temps d'un atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je démarre un minuteur partagé visible de tous, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Minuteur visible par tous les participants. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
