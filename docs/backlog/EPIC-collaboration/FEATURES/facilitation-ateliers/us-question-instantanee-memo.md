# US30.3.9 — Question instantanée & Mémo

**En tant que** facilitateur
**Je veux** lancer des questions instantanées à réponse immédiate et des capsules de contenu asynchrones (Mémo)
**Afin de** interpeller et informer l'audience en continu

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'animateur pose une question instantanée et reçoit des réponses immédiates, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Capsules de contenu asynchrones | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
