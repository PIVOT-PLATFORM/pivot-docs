# US30.3.4 — Gestion de l'attention

**En tant que** facilitateur
**Je veux** suivre un participant ou ramener tout le monde sur une zone donnée
**Afin de** maintenir l'attention du groupe pendant l'atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je ramène tous les participants sur une zone du board, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Ramener tout le monde sur une zone donnée | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
