# US30.3.3 — Mode présentation

**En tant que** facilitateur
**Je veux** naviguer séquentiellement par cadres en mode présentation, sans quitter l'outil
**Afin de** dérouler l'ordre du jour d'un atelier de façon guidée

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je passe en mode présentation et navigue de cadre en cadre, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Guidage de l'ordre du jour sans quitter l'outil | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
