# US30.3.7 — Visites guidées asynchrones

**En tant que** facilitateur
**Je veux** enregistrer des visites guidées audio/vidéo du board (type Talktrack), consultables pendant l'interaction
**Afin de** collaborer de façon asynchrone sur un board

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'enregistre une visite guidée du board consultable en asynchrone, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Consultable pendant l'interaction | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
