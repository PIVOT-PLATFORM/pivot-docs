# US30.7.1 — Intégration visioconférence 1-clic

**En tant que** utilisateur
**Je veux** ouvrir le board dans Teams, Meet ou Zoom en un clic, sans changement d'application ni réauthentification
**Afin de** collaborer sur le board pendant une visioconférence sans friction

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'ouvre le board dans Teams en un clic sans me réauthentifier, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Ouverture du board dans Teams/Meet/Zoom sans changement d'application ni réauthentification. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
