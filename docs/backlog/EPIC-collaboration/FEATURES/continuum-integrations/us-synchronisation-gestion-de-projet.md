# US30.7.2 — Synchronisation gestion de projet

**En tant que** utilisateur
**Je veux** synchroniser le board de façon bidirectionnelle avec l'outil de gestion de projet (Jira, Azure DevOps, Asana, Wrike)
**Afin de** transformer les idées d'un atelier en tâches suivies

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je convertis une idée en tâche Jira et vois le retour de statut, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Azure DevOps | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
