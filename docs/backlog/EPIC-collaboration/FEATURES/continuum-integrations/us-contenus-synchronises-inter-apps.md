# US30.7.3 — Contenus synchronisés inter-apps

**En tant que** utilisateur
**Je veux** partager des blocs vivants synchronisés (type Loop) entre board, messagerie, e-mails et documents
**Afin de** garder un contenu unique et à jour à travers les outils

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je crée un bloc synchronisé et le vois se mettre à jour dans un autre outil, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Messagerie | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
