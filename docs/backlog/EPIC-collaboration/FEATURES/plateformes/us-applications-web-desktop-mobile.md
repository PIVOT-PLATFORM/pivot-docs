# US30.10.1 — Applications web, desktop, mobile

**En tant que** utilisateur
**Je veux** utiliser des applications web, desktop et mobile/tablette avec parité de participation
**Afin de** participer depuis n'importe quel appareil

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when web (navigateurs récents), then le résultat est visible et persistant pour tous les participants | ⬜ |
| Desktop | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
