# US22.13.1 — Sièges légers participants

**En tant que** utilisateur
**Je veux** proposer des sièges légers, gratuits ou à très bas coût, pour les participants occasionnels
**Afin de** faire participer largement sans exploser le budget de licences

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when sièges gratuits ou très bas coût (type collab ~3 $) pour participants occasionnels et parties prenantes, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Sièges gratuits ou très bas coût (type Collab ~3 $) pour participants occasionnels et parties prenantes. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
