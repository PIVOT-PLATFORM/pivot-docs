# US30.12.1 — API publique documentée

**En tant que** utilisateur
**Je veux** disposer d'une API REST et d'un SDK documentés pour l'automatisation et les intégrations tierces
**Afin de** étendre et intégrer l'outil au système d'information

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un développeur appelle l'API REST documentée pour automatiser une action, then le résultat est visible et persistant pour tous les participants | ⬜ |
| API REST/SDK pour automatisation et intégrations tierces. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
