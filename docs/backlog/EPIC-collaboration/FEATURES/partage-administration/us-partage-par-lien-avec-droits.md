# US30.8.1 — Partage par lien avec droits

**En tant que** utilisateur
**Je veux** partager un board par lien avec des portées privé/équipe/organisation/externe et des rôles éditeur, commentateur, lecteur révocables
**Afin de** contrôler finement qui accède au board et avec quels droits

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je génère un lien de partage avec un rôle donné puis le révoque, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Rôles éditeur | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
