# US30.8.2 — Hiérarchie des espaces

**En tant que** utilisateur
**Je veux** organiser les boards en hiérarchie organisation > équipes > projets, avec brouillons personnels et recherche/tri
**Afin de** retrouver et ranger facilement les boards à l'échelle

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je classe un board dans un projet puis le retrouve par recherche, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Avec brouillons personnels et recherche/tri des boards | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
