# US30.8.4 — Accès invité sans compte

**En tant que** utilisateur
**Je veux** rejoindre un board par lien ou code sans créer de compte, avec des droits restreints à la participation
**Afin de** faire participer des invités sans aucune friction

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un invité rejoint le board par code sans créer de compte, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Droits restreints à la participation | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
