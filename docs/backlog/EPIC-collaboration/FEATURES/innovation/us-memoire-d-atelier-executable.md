# US30.14.1 — Mémoire d'atelier exécutable

**En tant que** utilisateur
**Je veux** disposer d'une mémoire d'atelier exécutable rouvrant automatiquement les actions à la rétro suivante, avec taux de réalisation
**Afin de** faire vivre les décisions après l'atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when les actions d'un atelier se rouvrent automatiquement à la rétrospective suivante, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Taux de réalisation | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
