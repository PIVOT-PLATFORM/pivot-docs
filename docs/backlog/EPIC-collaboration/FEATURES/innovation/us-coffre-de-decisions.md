# US30.14.2 — Coffre de décisions

**En tant que** utilisateur
**Je veux** consigner les décisions dans un coffre horodaté, signé et infalsifiable (qui, quoi, options, vote), exportable vers gouvernance/audit
**Afin de** assurer une traçabilité opposable des décisions

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when une décision est enregistrée signée et horodatée dans le coffre, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Signé et infalsifiable des décisions (qui | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
