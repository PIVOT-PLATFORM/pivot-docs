# US30.14.7 — IA souveraine embarquée

**En tant que** utilisateur
**Je veux** faire du clustering, de la synthèse et de la génération sur un modèle IA local, sans envoi au cloud
**Afin de** bénéficier de l'IA même en environnement souverain ou air-gap

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'IA clusterise les notes sur un modèle local sans transit cloud, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Sans envoi au cloud | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
