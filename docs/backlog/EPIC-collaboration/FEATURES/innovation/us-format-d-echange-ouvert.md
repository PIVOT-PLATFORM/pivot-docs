# US30.14.6 — Format d'échange ouvert

**En tant que** utilisateur
**Je veux** disposer d'un format d'échange ouvert (objets, positions, liens, auteurs) inter-outils
**Afin de** garantir une réversibilité totale entre outils

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'exporte un board au format ouvert puis le réimporte dans un autre outil, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Positions | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
