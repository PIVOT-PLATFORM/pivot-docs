# US30.14.8 — Board accessible non visuel

**En tant que** utilisateur
**Je veux** obtenir une restitution structurée (vocale, plan textuel navigable) du contenu spatial du canevas
**Afin de** rendre le board accessible aux personnes malvoyantes

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un utilisateur malvoyant navigue le board via une restitution textuelle structurée, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Plan textuel navigable) du contenu spatial du canevas pour malvoyants | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
