# US22.14.4 — Équité de participation

**En tant que** facilitateur
**Je veux** consulter un tableau de bord animateur d'équité de participation, avec garde-fous RGPD (agrégation, consentement)
**Afin de** favoriser une participation équilibrée dans le respect du RGPD

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'animateur consulte la répartition agrégée des contributions, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Signaux | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
