# US30.4.1 — Bibliothèque de modèles

**En tant que** utilisateur
**Je veux** accéder à une bibliothèque de modèles prêts à l'emploi (brainstorming, rétrospective, Kanban, SWOT, parcours client, plan d'action)
**Afin de** démarrer un atelier sans repartir d'une page blanche

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je choisis un modèle et l'instancie sur un nouveau board, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Rétrospective | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
