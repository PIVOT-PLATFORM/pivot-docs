# US30.1.7 — Sections / cadres (frames)

**En tant que** participant
**Je veux** regrouper des objets dans des cadres (frames) déplaçables d'un bloc
**Afin de** structurer le board et préparer un mode présentation

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je crée un cadre regroupant plusieurs objets, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Déplaçables d'un bloc | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
