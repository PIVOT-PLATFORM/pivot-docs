# US30.1.6 — Organisation des objets

**En tant que** participant
**Je veux** sélectionner, grouper, aligner, verrouiller et copier/coller plusieurs objets à la fois
**Afin de** organiser efficacement le contenu d'un board dense

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je sélectionne plusieurs objets et les groupe, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Groupement | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
