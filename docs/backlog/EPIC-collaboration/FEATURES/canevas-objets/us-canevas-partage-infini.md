# US30.1.1 — Canevas partagé infini

**En tant que** participant
**Je veux** un canevas zoomable et navigable sans limite de taille, utilisable à la souris, au tactile et au stylet
**Afin de** disposer d'un espace de travail visuel sans contrainte pour l'équipe

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when canevas zoomable et navigable sans limite fonctionnelle de taille, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Utilisable souris | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
