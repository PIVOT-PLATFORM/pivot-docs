# US30.1.5 — Insertion d'images et fichiers

**En tant que** participant
**Je veux** importer des images, des PDF et des documents sur le canevas et les annoter par-dessus
**Afin de** rassembler tous les supports d'un atelier au même endroit

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'importe une image ou un PDF et l'annote, then le résultat est visible et persistant pour tous les participants | ⬜ |
| PDF et documents sur le canevas avec annotation par-dessus | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
