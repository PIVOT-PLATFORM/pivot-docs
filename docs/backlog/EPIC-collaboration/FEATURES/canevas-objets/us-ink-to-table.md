# US30.1.10 — Ink-to-table

**En tant que** participant
**Je veux** convertir un quadrillage dessiné en tableau éditable (ink-to-table)
**Afin de** créer des tableaux structurés à partir d'un dessin

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je dessine un quadrillage et l'outil le convertit en tableau éditable, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Conversion d'un quadrillage dessiné en tableau éditable. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
