# US30.1.13 — Mini-carte et navigation sur grands boards

**En tant que** participant
**Je veux** disposer d'une mini-carte (mini-map), d'un zoom-to-fit et de raccourcis de navigation vers les zones/cadres du board
**Afin de** me repérer et me déplacer efficacement sur un très grand board de management visuel

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un board dont le contenu dépasse l'écran, when j'ouvre la mini-carte, then je vois une vue d'ensemble cliquable qui recentre le canevas sur la zone choisie | ⬜ |
| Given plusieurs cadres/zones nommés, when j'utilise la navigation par zones, then je peux sauter directement d'une zone à l'autre sans défilement manuel | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
