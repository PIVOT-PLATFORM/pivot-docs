# US22.1.3 — Formes, connecteurs, texte

**En tant que** participant
**Je veux** ajouter des formes géométriques, des connecteurs magnétiques alignés sur grille et des zones de texte
**Afin de** structurer visuellement des schémas et des diagrammes simples

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je place une forme et la relie par un connecteur magnétique, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Connecteurs magnétiques alignés sur grille | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
