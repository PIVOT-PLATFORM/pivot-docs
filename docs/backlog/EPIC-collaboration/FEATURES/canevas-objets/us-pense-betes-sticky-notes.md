# US30.1.2 — Pense-bêtes (sticky notes)

**En tant que** participant
**Je veux** créer rapidement des pense-bêtes colorés avec attribution d'auteur paramétrable
**Afin de** capturer des idées à la volée pendant un atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je crée un pense-bête et lui attribue une couleur, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Attribution d'auteur paramétrable | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
