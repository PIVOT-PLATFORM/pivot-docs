# US30.1.11 — Liens enrichis et lecture vidéo intégrée

**En tant que** participant
**Je veux** coller un lien sur le canevas et obtenir un aperçu enrichi (titre, image), avec lecture d'une vidéo en ligne directement dans le board
**Afin de** partager une ressource externe sans faire quitter le board aux autres participants

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je colle une URL, then le système affiche une carte d'aperçu (titre, image) sans quitter le board | ⬜ |
| Lecture vidéo intégrée pour les liens de plateformes vidéo supportées | ⬜ |
| Error : given une URL invalide ou inaccessible, system affiche un lien simple sans bloquer la saisie | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
