# US30.1.9 — Capture de pense-bêtes physiques

**En tant que** participant
**Je veux** numériser des post-its papier par photo, avec reconnaissance de texte
**Afin de** récupérer un atelier physique dans le board numérique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je photographie des post-its papier et l'outil les numérise avec leur texte, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Numérisation photo des post-its papier avec reconnaissance de texte. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
