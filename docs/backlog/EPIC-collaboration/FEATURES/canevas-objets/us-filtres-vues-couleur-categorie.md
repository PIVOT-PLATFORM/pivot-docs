# US30.1.12 — Filtres et vues par couleur / catégorie

**En tant que** participant
**Je veux** filtrer et masquer les objets du board par couleur, catégorie ou étiquette, et enregistrer des vues filtrées réutilisables
**Afin de** garder un board dense lisible et exploiter le management visuel sans le noyer

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un board contenant des objets de plusieurs couleurs/catégories, when j'applique un filtre par couleur ou catégorie, then seuls les objets correspondants restent mis en avant et le résultat est cohérent pour le participant qui filtre | ⬜ |
| Given un filtre appliqué, when je l'enregistre comme vue, then la vue filtrée est rappelable ultérieurement sans re-paramétrage | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
