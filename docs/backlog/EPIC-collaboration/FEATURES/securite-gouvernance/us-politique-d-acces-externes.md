# US30.9.4 — Politique d'accès externes

**En tant que** RSSI
**Je veux** disposer d'une politique RSSI écrite avant déploiement encadrant invités, anonymes et boards ouverts
**Afin de** arbitrer explicitement l'équilibre sécurité/fluidité

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when politique rssi écrite avant déploiement : invités autorisés, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Anonymes | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
