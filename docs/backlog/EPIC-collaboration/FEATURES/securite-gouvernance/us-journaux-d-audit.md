# US30.9.5 — Journaux d'audit

**En tant que** administrateur
**Je veux** consulter des journaux d'audit des accès, partages et actions d'administration, exportables vers le SIEM
**Afin de** tracer et superviser les actions sensibles

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'administrateur exporte les journaux d'audit vers le SIEM, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Partages et actions d'administration | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
