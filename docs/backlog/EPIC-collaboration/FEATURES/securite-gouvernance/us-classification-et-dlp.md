# US30.9.6 — Classification et DLP

**En tant que** RSSI
**Je veux** classifier les boards et restreindre le partage externe par politique, avec filigranes (DLP)
**Afin de** prévenir les fuites de données sensibles

| Critère | 🤖 Dev |

| Given le canevas de collaboration, when l'administrateur classifie un board et bloque son partage externe par politique DLP, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Restriction du partage externe par politique | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
