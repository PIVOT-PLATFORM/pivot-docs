# US22.9.7 — Résidence des données UE

**En tant que** administrateur
**Je veux** héberger les données en UE par défaut ou en option contractuelle
**Afin de** garantir la résidence des données en Europe

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'organisation exige la résidence des données en UE, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Localisation UE des données par défaut ou en option contractuelle. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
