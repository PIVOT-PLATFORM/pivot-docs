# US30.9.9 — Provisionnement SCIM

**En tant que** administrateur
**Je veux** provisionner et déprovisionner automatiquement les comptes depuis l'annuaire via SCIM
**Afin de** automatiser le cycle de vie des comptes

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'administrateur active le provisionnement SCIM depuis l'annuaire, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Provisionnement/déprovisionnement automatique des comptes depuis l'annuaire. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
