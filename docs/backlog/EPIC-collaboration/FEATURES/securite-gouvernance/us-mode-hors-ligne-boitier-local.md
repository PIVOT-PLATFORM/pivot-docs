# US22.9.11 — Mode hors ligne (boîtier local)

**En tant que** administrateur
**Je veux** collaborer sur un réseau Wi-Fi local fermé (type Box), sans transit Internet
**Afin de** travailler en toute confidentialité sans connexion externe
