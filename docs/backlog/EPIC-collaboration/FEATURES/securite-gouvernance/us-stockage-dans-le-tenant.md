# US30.9.10 — Stockage dans le tenant

**En tant que** administrateur
**Je veux** stocker les boards dans l'espace cloud de l'organisation (type OneDrive), avec rétention, e-discovery et DLP hérités
**Afin de** aligner la gouvernance des boards sur celle du tenant

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un board est stocké dans le tenant et hérite de la rétention et du DLP, then le résultat est visible et persistant pour tous les participants | ⬜ |
| E-discovery | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
