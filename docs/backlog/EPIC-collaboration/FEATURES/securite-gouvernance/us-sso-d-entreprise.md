# US30.9.1 — SSO d'entreprise

**En tant que** RSSI
**Je veux** me connecter via le SSO d'entreprise en SAML 2.0 / OIDC, avec MFA héritée des politiques de l'organisation
**Afin de** sécuriser l'accès et simplifier l'authentification des collaborateurs

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je m'authentifie via le fournisseur d'identité SAML 2.0 / OIDC de l'organisation, then le résultat est visible et persistant pour tous les participants | ⬜ |
| MFA héritée des politiques de l'organisation | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : conforme aux politiques de sécurité et de conformité (RGPD, audit, droits d'accès) | ⬜ |
