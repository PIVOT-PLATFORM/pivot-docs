# US30.2.6 — Audio/vidéo natif au board

**En tant que** participant
**Je veux** disposer d'un tchat audio (a minima) intégré au board, sans outil externe
**Afin de** échanger de vive voix sans quitter le board

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when tchat audio (a minima) intégré au board, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Sans dépendance à un outil externe | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
