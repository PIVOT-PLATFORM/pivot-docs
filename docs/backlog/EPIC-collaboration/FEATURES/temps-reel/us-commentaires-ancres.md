# US30.2.3 — Commentaires ancrés

**En tant que** participant
**Je veux** ouvrir des fils de discussion ancrés sur les objets, avec mentions @ et notifications
**Afin de** échanger dans le contexte précis d'un élément du board

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'ajoute un commentaire ancré sur un objet et mentionne un collègue, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Mentions @ | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
