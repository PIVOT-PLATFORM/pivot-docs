# US22.2.1 — Édition simultanée temps réel

**En tant que** participant
**Je veux** co-éditer le board à plusieurs en temps réel avec une propagation inférieure à 1 s
**Afin de** travailler simultanément sans conflit ni latence perceptible

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when co-édition multi-utilisateurs avec propagation < 1 s, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Co-édition multi-utilisateurs avec propagation < 1 s. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
