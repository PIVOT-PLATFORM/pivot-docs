# US30.2.5 — Historique de versions

**En tant que** participant
**Je veux** consulter des versions horodatées du board et les restaurer
**Afin de** revenir à un état antérieur en cas d'erreur

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je consulte l'historique et restaure une version antérieure, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Versions horodatées du board avec restauration. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
