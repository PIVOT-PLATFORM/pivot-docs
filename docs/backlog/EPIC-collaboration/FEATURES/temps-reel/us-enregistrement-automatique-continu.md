# US22.2.4 — Enregistrement automatique continu

**En tant que** participant
**Je veux** bénéficier d'une sauvegarde cloud permanente avec reprise transparente sur tout appareil
**Afin de** ne jamais perdre une contribution

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je modifie le board et retrouve mon travail intact sur un autre appareil, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Reprise transparente sur tout appareil | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
