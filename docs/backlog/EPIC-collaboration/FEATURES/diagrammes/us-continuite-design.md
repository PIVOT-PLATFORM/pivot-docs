# US22.5.4 — Continuité design

**En tant que** utilisateur
**Je veux** importer des maquettes réelles éditables/liées dans les parcours utilisateurs, avec circulation board <-> outil design
**Afin de** assurer la continuité entre atelier et travail de design

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when j'importe une maquette liée et la fais circuler entre board et outil design, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Circulation board <-> outil design | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
