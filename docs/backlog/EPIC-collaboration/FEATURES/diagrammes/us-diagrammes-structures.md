# US30.5.1 — Diagrammes structurés

**En tant que** utilisateur
**Je veux** créer des diagrammes structurés (organigrammes, flux) avec des bibliothèques de formes étendues UML et BPMN
**Afin de** modéliser des processus et des systèmes de façon rigoureuse

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je construis un diagramme de flux avec des formes BPMN, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Diagrammes de flux | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
