# US30.5.2 — Mind mapping

**En tant que** utilisateur
**Je veux** créer des cartes mentales avec ajout rapide de nœuds au clavier
**Afin de** structurer des idées en arborescence rapidement

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je crée une carte mentale et ajoute des nœuds au clavier, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Cartes mentales avec création rapide de nœuds au clavier. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |
