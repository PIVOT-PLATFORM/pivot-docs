# US30.6.2 — IA : génération par invite

**En tant que** utilisateur
**Je veux** générer par invite en langage naturel des trames d'atelier, modèles, plannings et diagrammes
**Afin de** accélérer la préparation d'un atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je décris un atelier en langage naturel et l'IA génère une trame, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Modèles | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
