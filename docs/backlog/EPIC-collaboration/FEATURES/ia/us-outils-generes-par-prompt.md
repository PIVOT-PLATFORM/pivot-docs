# US30.6.5 — Outils générés par prompt

**En tant que** utilisateur
**Je veux** créer par invite des plugins/skills personnalisés, partageables dans l'organisation
**Afin de** étendre l'outil sans développement classique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je décris un outil par invite et l'IA génère un plugin partageable, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Partageables dans l'organisation | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
