# US30.6.6 — Agents IA collaboratifs

**En tant que** utilisateur
**Je veux** faire opérer des agents IA collaboratifs sur le board avec plusieurs utilisateurs (type Flows/Sidekicks)
**Afin de** déléguer des tâches à des agents IA en cours d'atelier

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un agent IA opère sur le board aux côtés des participants, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Agents opérant sur le board avec plusieurs utilisateurs (type Flows/Sidekicks). | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
