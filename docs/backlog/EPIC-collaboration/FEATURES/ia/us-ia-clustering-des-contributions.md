# US30.6.1 — IA : clustering des contributions

**En tant que** utilisateur
**Je veux** un clustering IA des contributions par thème, mot-clé ou sentiment avec étiquetage des groupes
**Afin de** synthétiser rapidement un grand volume de contributions

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when je lance le clustering IA sur les notes et obtiens des groupes étiquetés, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Regroupement automatique des notes par thème/mot-clé/sentiment avec étiquetage des groupes. | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
