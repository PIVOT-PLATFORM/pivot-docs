# US22.6.4 — Gouvernance de l'IA

**En tant que** administrateur
**Je veux** gouverner l'IA : désactivation par l'administrateur, quotas visibles, localisation des traitements et non-réutilisation pour l'entraînement
**Afin de** maîtriser l'usage de l'IA dès le premier jour

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when l'administrateur désactive l'IA ou consulte les quotas, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Quotas visibles | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
