# US22.15.5 — Réseau d'animateurs référents

**En tant que** DSI/RSSI/PMO
**Je veux** former un réseau d'animateurs référents par direction, avec un parcours de formation à la facilitation
**Afin de** faire de l'adoption un projet accompagné

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Réseau d'animateurs référents » est arbitrée, then former un réseau d'animateurs par direction est acté et documenté | ⬜ |
| Parcours de formation facilitation est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
