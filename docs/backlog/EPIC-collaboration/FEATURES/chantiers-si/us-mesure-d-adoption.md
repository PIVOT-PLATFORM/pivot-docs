# US30.15.6 — Mesure d'adoption

**En tant que** DSI/RSSI/PMO
**Je veux** mesurer l'adoption par des KPI d'usage réel (boards actifs, réunions outillées, ateliers avec actions converties)
**Afin de** piloter l'adoption sur l'usage plutôt que sur les licences

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Mesure d'adoption » est arbitrée, then kpi : boards actifs est acté et documenté | ⬜ |
| Taux de réunions outillées est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
