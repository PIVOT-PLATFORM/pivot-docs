# US30.15.1 — Standardisation du parc

**En tant que** DSI/RSSI/PMO
**Je veux** acter la décision d'un outil socle unique aligné sur l'écosystème plus une exception spécialisée gouvernée au maximum, en bloquant le reste
**Afin de** mettre fin au shadow IT du whiteboard

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Standardisation du parc » est arbitrée, then décision : 1 outil socle aligné écosystème + 1 exception spécialisée gouvernée max est acté et documenté | ⬜ |
| Blocage/non-remboursement du reste est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
