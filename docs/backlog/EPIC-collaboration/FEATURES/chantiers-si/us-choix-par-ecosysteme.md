# US30.15.2 — Choix par écosystème

**En tant que** DSI/RSSI/PMO
**Je veux** adopter une grille de choix par écosystème (M365 -> Whiteboard, Figma -> FigJam, Wrike -> Klaxoon, transverse -> Miro)
**Afin de** ne jamais choisir un outil contre son écosystème

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Choix par écosystème » est arbitrée, then grille de choix : m365 -> whiteboard est acté et documenté | ⬜ |
| Figma -> FigJam est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
