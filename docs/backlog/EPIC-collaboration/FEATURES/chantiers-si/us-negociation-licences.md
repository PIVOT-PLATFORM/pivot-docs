# US30.15.8 — Négociation licences

**En tant que** DSI/RSSI/PMO
**Je veux** négocier des sièges légers pour occasionnels et un engagement pluriannuel indexé sur l'usage réel, à plafonds transparents
**Afin de** maîtriser le coût des licences dans la durée

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Négociation licences » est arbitrée, then sièges légers pour occasionnels est acté et documenté | ⬜ |
| Engagement pluriannuel indexé sur usage réel est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
