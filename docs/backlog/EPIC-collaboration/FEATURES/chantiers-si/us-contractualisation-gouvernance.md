# US30.15.3 — Contractualisation gouvernance

**En tant que** DSI/RSSI/PMO
**Je veux** inscrire au contrat les exigences de gouvernance : classification, audit, partage externe, localisation UE, non-entraînement IA, réversibilité
**Afin de** sécuriser juridiquement le déploiement

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le cadre de gouvernance SI, when la décision « Contractualisation gouvernance » est arbitrée, then exigences contractuelles : classification est acté et documenté | ⬜ |
| Audit est formalisé dans un livrable diffusable aux directions concernées | ⬜ |
| Error : given un cas non couvert par la décision, system escalade vers le comité d'arbitrage DSI/RSSI/PMO | ⬜ |
| Security/Gouvernance : la décision est tracée et revue périodiquement dans le registre de gouvernance | ⬜ |
