# US28.8.1 — Adaptateur Formbricks

> Stub phase-3 — ACs à détailler par PO Agent lors de Gate 1 avant implémentation.

**En tant que** BA ou PO
**Je veux** intégrer **Formbricks** pour les quiz/formulaires/sondages déclenchant des événements
**Afin de** disposer d'un outil de formulaires dédié, en complément ou à la place des briques natives **Session** ([E19](../../../EPIC-module-session/README.md)) et **Pivot Forms** ([E42](pathname:///pivot-docs/backlog/EPIC-pivot-forms/)) selon le choix de mon instance

## Critères d'acceptation (outline — Gate 1 PO Agent)

| Critère | 🤖 Dev |
|---------|--------|
| Adaptateur `adapter-formbricks` conforme au contrat PivotAdapter (EN28.3) | ⬜ |
| Une réponse de formulaire Formbricks émet un événement exploitable | ⬜ |
| Une instance peut activer Session/Pivot Forms natifs, Formbricks, ou les deux simultanément — coexistence, aucune exclusion mutuelle | ⬜ |
