# US28.7.1 — Lien Scrumlr

> Stub phase-3 — ACs à détailler par PO Agent lors de Gate 1 avant implémentation.

**En tant que** Scrum Master ou membre d'équipe
**Je veux** lancer une rétrospective **Scrumlr** en un clic depuis le portail
**Afin de** disposer d'un outil de rétrospective dédié, en complément ou à la place du module natif **Rétrospective** ([E20](../../../EPIC-retrospective/README.md)) selon le choix de mon instance
