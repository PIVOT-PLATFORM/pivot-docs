# EN18.7 — Hébergement France/UE

**Type d'enabler** : sécurité
**Objectif technique** : Hébergement France ou UE documenté et contractualisé ; option souveraine pour les portefeuilles sensibles.
**Justification** : Dossier §8-I4
**Critères de complétion** :
- [ ] Hébergement des données en France ou UE documenté et contractualisé
- [ ] Option d'hébergement souverain disponible pour les portefeuilles sensibles
- [ ] Résidence des données par défaut vérifiable et attestée
- [ ] Alignement de la classe d'hébergement sur la classification de sensibilité (cf. PP-028)
