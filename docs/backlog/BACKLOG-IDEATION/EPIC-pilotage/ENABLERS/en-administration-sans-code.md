# EN18.6 — Administration sans code

**Type d'enabler** : infrastructure
**Objectif technique** : Administration fonctionnelle autonome : champs, formulaires, référentiels, organisation, modèles, libellés.
**Justification** : Dossier §6.1 : autonomie = maîtrise du TCO
**Critères de complétion** :
- [ ] Un administrateur fonctionnel configure champs, formulaires et référentiels sans code
- [ ] Personnalisation de l'organisation, des modèles et des libellés en autonomie
- [ ] Modifications de configuration versionnées et réversibles
- [ ] Documentation d'administration fonctionnelle disponible
