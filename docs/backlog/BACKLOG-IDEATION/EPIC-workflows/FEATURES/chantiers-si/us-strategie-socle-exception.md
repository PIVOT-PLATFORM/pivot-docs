# US29.14.4 — Stratégie socle + exception

**En tant que** DSI/architecte
**Je veux** définir un socle gouverné (PA si M365, sinon Zapier) + une exception technique souveraine (n8n/Activepieces), avec brique IA-native éventuelle sous gouvernance stricte
**Afin de** structurer l'offre d'automatisation de l'organisation

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le contexte SI, when l'équipe définit la stratégie, then un socle gouverné est choisi (PA si M365, sinon Zapier) | ⬜ |
| Given des besoins techniques/souverains, when ils dépassent le socle, then une exception (n8n/Activepieces) est cadrée | ⬜ |
| Security/Gouvernance : toute brique IA-native est encadrée par une gouvernance stricte documentée | ⬜ |
