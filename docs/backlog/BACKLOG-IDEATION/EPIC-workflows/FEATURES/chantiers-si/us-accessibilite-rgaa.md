# US29.14.11 — Accessibilité RGAA

**En tant que** DSI/architecte
**Je veux** vérifier la conformité RGAA 4 / WCAG 2.1 AA des interfaces (builder, formulaires, approbations) exposées aux agents publics et collaborateurs
**Afin de** respecter l'exigence d'accessibilité des organisations françaises

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given les interfaces exposées (builder, formulaires, approbations), when on les audite, then leur conformité RGAA 4 / WCAG 2.1 AA est vérifiée | ⬜ |
| Given un défaut d'accessibilité, when il est identifié, then il est documenté et priorisé pour correction | ⬜ |
| A11y : les interfaces sont navigables au clavier et compatibles lecteurs d'écran (RGAA 4 / WCAG 2.1 AA) | ⬜ |
