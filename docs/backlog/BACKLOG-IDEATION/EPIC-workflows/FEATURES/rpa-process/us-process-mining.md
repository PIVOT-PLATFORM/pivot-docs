# US29.10.3 — Process mining

**En tant que** utilisateur métier
**Je veux** ingérer des journaux, cartographier les processus, détecter les goulots et suivre des KPI personnalisés
**Afin de** identifier les processus à automatiser en priorité

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given des journaux d'événements, when je les ingère, then une cartographie du processus réel est produite | ⬜ |
| Given une cartographie, when je l'analyse, then les goulots et KPI personnalisés sont mis en évidence | ⬜ |
| Security/Gouvernance : les données de journaux ingérées respectent les règles de confidentialité définies | ⬜ |
