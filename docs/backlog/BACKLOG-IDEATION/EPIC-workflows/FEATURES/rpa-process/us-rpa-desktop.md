# US29.10.1 — RPA desktop

**En tant que** opérateur
**Je veux** automatiser des interfaces Windows via un enregistreur, des sélecteurs, en mode attended/unattended, sur machines hébergées
**Afin de** automatiser le legacy sans API

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une application Windows, when j'enregistre une séquence, then elle est rejouable via sélecteurs | ⬜ |
| Given un robot, when je l'exécute en mode attended ou unattended, then il agit sur l'interface de la machine hébergée | ⬜ |
| Error : given un élément d'interface introuvable, system met le robot en échec avec capture du contexte | ⬜ |
