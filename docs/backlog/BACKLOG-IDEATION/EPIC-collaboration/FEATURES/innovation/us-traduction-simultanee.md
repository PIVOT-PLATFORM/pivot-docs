# US30.14.3 — Traduction simultanée

**En tant que** utilisateur
**Je veux** écrire et lire les contributions dans ma langue grâce à une traduction simultanée sur le canevas
**Afin de** collaborer sans barrière de langue dans une équipe multinationale

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le canevas de collaboration, when un participant écrit dans sa langue et les autres la lisent traduite, then le résultat est visible et persistant pour tous les participants | ⬜ |
| Traduction temps réel sur canevas | ⬜ |
| Error : given une entrée invalide ou une coupure réseau, system préserve les contributions et affiche un état cohérent | ⬜ |
| Security/Gouvernance : action journalisée et respectant les droits d'accès du participant | ⬜ |
