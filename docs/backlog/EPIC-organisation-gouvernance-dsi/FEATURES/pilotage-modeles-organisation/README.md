# F49.1 — Pilotage des modèles d'organisation

**Description** : Permettre à une DSI de cartographier sa propre organisation (unités,
hiérarchie, rattachements) et de sélectionner/documenter le modèle de gouvernance SI (parmi les 5
du benchmark) qui correspond à sa structure, avec justification et révision dans le temps.

**Bénéfice utilisateur** : la DSI Groupe dispose d'une vue structurée et actionnable de son
organisation et de son modèle de gouvernance, réutilisable comme référentiel par les autres
domaines (architecture, données, citizen dev, cybersécurité).

**US rattachées** : [US49.1.1](us-cartographie-organisation.md), [US49.1.2](us-selection-modele-gouvernance.md)

**Critères de succès (feature-level)** :
- [ ] Une DSI Groupe peut modéliser son organigramme et y rattacher ses équipes existantes ([E15](../../../EPIC-equipes/README.md))
- [ ] Une DSI Groupe peut choisir et justifier un modèle de gouvernance parmi les 5 du catalogue (EN49.3), et le réviser

**Hors périmètre** :
- [ ] La réimplémentation fonctionnelle des modèles eux-mêmes (ex. portail développeur pour Team
      Topologies, marketplace API pour Platform + Marketplace) — hors périmètre de cette feature,
      qui reste de la documentation/aide à la décision
