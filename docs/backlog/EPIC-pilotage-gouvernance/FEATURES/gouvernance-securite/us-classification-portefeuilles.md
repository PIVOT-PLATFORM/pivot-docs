# US35.1.5 — Classification des portefeuilles

**En tant que** DSI
**Je veux** classifier la sensibilité des projets (sécurité, foncier, précontentieux) et aligner l'hébergement par classe
**Afin d'** appliquer la doctrine 'cloud au centre' avec le bon niveau de protection selon la sensibilité

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un projet, when un administrateur le classifie, then une classe de sensibilité (sécurité, foncier, précontentieux…) lui est attribuée | ⬜ |
| L'hébergement applicable est aligné sur la classe de sensibilité du portefeuille | ⬜ |
| Error : given un projet sensible sur un hébergement non conforme à sa classe, system alerte | ⬜ |
| Security/Gouvernance : les changements de classification sont tracés et réservés aux rôles autorisés | ⬜ |
