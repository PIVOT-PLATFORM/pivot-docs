# US11.6.3 — Ajustement par la vélocité du sprint précédent

**En tant que** Scrum Master
**Je veux** pondérer la capacité prévisionnelle par la **vélocité réelle** du/des sprint(s) précédent(s)
**Afin de** planifier sur la réalité mesurée plutôt que sur la théorie

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given la vélocité des N sprints précédents (F11.4), when je planifie, then une capacité prévisionnelle (en points) est proposée à partir de la moyenne/tendance | ⬜ |
| Given une vélocité régulière, when on l'exploite, then l'intervalle de confiance est resserré ; s'il est irrégulier, il est élargi | ⬜ |
| Given un **premier sprint sans historique**, then repli sur la capacité en jours-homme × facteur (sans vélocité) | ⬜ |
