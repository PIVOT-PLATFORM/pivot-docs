# US11.6.5 — Capacité nette consolidée (membre → sprint → incrément/PI)

**En tant que** RTE / Scrum Master
**Je veux** consolider la capacité nette du membre au sprint, puis à l'incrément / PI
**Afin de** disposer d'une capacité fiable à chaque maille pour engager le bon périmètre

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given les capacités des membres, when on agrège, then la **capacité du sprint** (jours-homme nets et/ou points) est calculée | ⬜ |
| Given les sprints d'un incrément/PI, when on consolide, then la **capacité du PI** = somme des sprints (IP retirée si SAFe) | ⬜ |
| Given un changement (absence, période, facteur, maturité, vélocité), when il survient, then la capacité **se recalcule à tous les niveaux** | ⬜ |
