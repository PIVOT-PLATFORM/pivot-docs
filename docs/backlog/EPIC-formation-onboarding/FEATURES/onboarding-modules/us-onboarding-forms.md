# US41.5.30 — Onboarding in-app — Pivot Forms (E42)

**En tant que** nouvel utilisateur du module
**Je veux** un **parcours d'onboarding in-app propre au module Pivot Forms** (tour guidé, points clés, checklist, empty states), branché sur le framework EN41.1
**Afin de** comprendre et adopter Pivot Forms directement dans l'outil

| Critère | 🤖 Dev |
