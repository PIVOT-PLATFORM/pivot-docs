# US27.7.1 — Conversations & 1:1 liées aux OKR

**En tant que** manager
**Je veux** tenir des **conversations / 1:1** rattachées aux OKR (le « C » de CFR de Doerr)
**Afin de** faire vivre les OKR par le dialogue plutôt que par le seul reporting
