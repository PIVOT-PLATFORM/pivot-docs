# EN18.8 — Option on-premise

**Type d'enabler** : infrastructure
**Objectif technique** : Installation sur site pour les organisations à contrainte de souveraineté maximale.
**Justification** : Dossier §6.1 ; devient Must si portefeuilles sensibles (cf. PP-028)
**Critères de complétion** :
- [ ] Installation on-premise documentée (déploiement, prérequis, exploitation)
- [ ] Données 100 % dans le périmètre de l'organisation, sans transit externe
- [ ] Procédure de mise à jour et de sauvegarde pour déploiement sur site
- [ ] Parité fonctionnelle documentée entre SaaS et on-premise
