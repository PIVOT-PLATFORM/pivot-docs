# EN18.4 — Localisation FR et RGAA

**Type d'enabler** : conformité
**Objectif technique** : Interface 100 % francophone ; conformité RGAA 4 avec déclaration d'accessibilité (obligation légale secteur public).
**Justification** : Cahiers ENF ; obligation pour les organismes publics
**Critères de complétion** :
- [ ] Interface entièrement localisée en français (libellés, messages, aides, exports)
- [ ] Conformité RGAA 4 / WCAG 2.1 AA vérifiée (navigation clavier, lecteurs d'écran, contrastes)
- [ ] Déclaration d'accessibilité publiée et accessible depuis l'application
- [ ] Audit d'accessibilité documenté avec plan de remédiation des non-conformités
