# EN18.3 — Cloud/SaaS et RGPD

**Type d'enabler** : conformité
**Objectif technique** : Déploiement SaaS ; RGPD avec DPA ; chiffrement transit/repos ; disponibilité >= 99,5 %.
**Justification** : Cahiers ENF
**Critères de complétion** :
- [ ] Déploiement SaaS opérationnel avec DPA signé et registre des traitements RGPD tenu à jour
- [ ] Chiffrement TLS 1.2+ en transit et AES-256 au repos vérifié sur l'ensemble des flux
- [ ] SLA de disponibilité >= 99,5 % mesuré et documenté (page de statut)
- [ ] Procédure de sauvegarde/restauration testée sans perte de données
