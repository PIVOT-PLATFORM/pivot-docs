# US18.18.5 — Portail de transparence

**En tant que** direction
**Je veux** publier vers les citoyens l'avancement des projets (carte, jalons, budgets consommés, open data)
**Afin d'** outiller la redevabilité démocratique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given des projets marqués publiables, when la direction publie, then avancement, carte, jalons et budgets consommés sont exposés au portail citoyen | ⬜ |
| Les données sont disponibles en open data (format ouvert) | ⬜ |
| Error : given un projet non marqué publiable, system l'exclut de la publication | ⬜ |
| A11y : le portail public est conforme RGAA 4 / WCAG 2.1 AA (obligation secteur public) | ⬜ |
