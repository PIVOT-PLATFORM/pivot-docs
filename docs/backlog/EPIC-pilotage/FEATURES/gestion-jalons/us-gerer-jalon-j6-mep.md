# US18.3.5 — Gérer le jalon J6 « Mise en Production (MEP) »

**En tant que** chef de projet (pilote d'activité)
**Je veux** gérer le jalon J6 (ex Go Try) renommé Mise en Production (MEP) avec une aide au format dans Description version
**Afin de** décrire la mise en production dans un format cohérent

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le jalon J6, when je le consulte, then il est intitulé Mise en Production (MEP) | ⬜ |
| Given le champ Description version du jalon J6, when je saisis, then une aide au format est proposée | ⬜ |
| Error : given une Description version ne respectant pas le format attendu, system guide l'utilisateur via l'aide au format | ⬜ |
| Security/Gouvernance : seul le chef de projet pilote de l'activité (ou un administrateur habilité) peut gérer le jalon J6 MEP | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |

## Hors périmètre
- Le jalon J7 (MES) et ses champs (Type de déploiement, Sites, tranches) sont couverts par une US dédiée.

## Notes d'implémentation
- Jalon J6 « Mise en Production (MEP) » de l'écran jalons (module pilotage).
- Aide au format dans le champ Description version.
