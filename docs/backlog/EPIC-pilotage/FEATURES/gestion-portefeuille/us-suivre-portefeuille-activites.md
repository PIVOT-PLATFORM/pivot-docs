# US18.5.1 — Suivre un portefeuille d'activités

**En tant que** gestionnaire de portefeuille (décideur / manager)
**Je veux** consulter et gérer un portefeuille d'activités
**Afin de** piloter la Division Numérique

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given un portefeuille d'activités, when je le consulte, then j'accède à l'ensemble des activités qui le composent | ⬜ |
| Given un portefeuille, when je le gère, then je peux organiser et suivre les activités pour piloter la Division Numérique | ⬜ |
| Error : given un portefeuille vide, system affiche un état vide explicite sans provoquer d'erreur | ⬜ |
| Security/Gouvernance : seul un gestionnaire de portefeuille habilité peut consulter et gérer le portefeuille correspondant | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |

## Hors périmètre
- Le contrôle des noms de portefeuille et la lisibilité de la liste sont couverts par des US dédiées.

## Notes d'implémentation
- Écran portefeuille (module pilotage) : consultation et gestion d'un portefeuille d'activités.
