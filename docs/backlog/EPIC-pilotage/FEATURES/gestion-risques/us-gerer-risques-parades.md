# US18.4.1 — Gérer les principaux risques et parades

**En tant que** chef de projet (pilote d'activité)
**Je veux** enregistrer et suivre les principaux risques et leurs parades
**Afin de** anticiper et maîtriser les risques de l'activité

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given le formulaire risques, when je saisis un risque, then je peux enregistrer le risque et la parade associée | ⬜ |
| Given des risques enregistrés, when je consulte l'activité, then je peux suivre les principaux risques et leurs parades | ⬜ |
| Given le formulaire risques, when je le renseigne, then des bulles d'information sont disponibles pour guider la saisie | ⬜ |
| Error : given un champ requis du risque non renseigné, system signale le champ manquant avant enregistrement | ⬜ |
| Security/Gouvernance : seul le chef de projet pilote de l'activité (ou un administrateur habilité) peut gérer les risques et parades | ⬜ |
| A11y : navigation clavier et compatibilité lecteur d'écran conformes WCAG 2.1 AA | ⬜ |

## Hors périmètre
- Le calcul d'un score de risque global n'est pas couvert par cette US.

## Notes d'implémentation
- Écran/formulaire risques de l'activité (module pilotage).
- Bulles d'information de guidage sur le formulaire risques.
