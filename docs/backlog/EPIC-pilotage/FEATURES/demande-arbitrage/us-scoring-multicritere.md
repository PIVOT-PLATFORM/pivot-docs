# US18.8.2 — Scoring multicritère

**En tant que** décideur (direction / élu)
**Je veux** noter les demandes selon des critères configurables (alignement, coût, risque, impact) avec des votes indépendants des décideurs
**Afin de** objectiver la priorisation et comparer les demandes entre elles

## Critères d'acceptation

| Critère | 🤖 Dev |
|---------|--------|
| Given une grille de critères configurée, when un décideur note une demande, then son vote est enregistré indépendamment des autres | ⬜ |
| Le score agrégé de chaque demande est calculé et comparable au sein du portefeuille | ⬜ |
| Error : given un critère non renseigné, system signale la notation incomplète avant validation | ⬜ |
| Security/Gouvernance : les votes des décideurs sont tracés et attribués (traçabilité de l'arbitrage) | ⬜ |
