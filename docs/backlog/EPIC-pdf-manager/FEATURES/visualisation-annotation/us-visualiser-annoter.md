# US45.2.1 — Consulter et annoter un document PDF

> Stub phase-3 — ACs à détailler par PO Agent lors de Gate 1 avant implémentation.

**En tant qu'** utilisateur ayant accès à un document
**Je veux** le consulter directement dans le navigateur et y ajouter des annotations (surlignage, commentaire, dessin, tampon)
**Afin de** collaborer sur le contenu sans le modifier

## Critères d'acceptation (outline — Gate 1 PO Agent)

| Critère | 🤖 Dev |
|---------|--------|
| Rendu in-browser (pages, miniatures, zoom, plein écran) | ⬜ |
| Annotations non destructives : surlignage, commentaire positionné, dessin libre, tampon | ⬜ |
| Export du PDF avec annotations aplaties | ⬜ |
| Droits : lecteur peut voir, éditeur peut annoter, propriétaire gère les partages | ⬜ |
| Sécurité : annotations rattachées à leur auteur, non modifiables par un tiers | ⬜ |
