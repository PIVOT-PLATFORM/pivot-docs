# US45.4.1 — Partager un document et suivre ses versions

> Stub phase-3 — ACs à détailler par PO Agent lors de Gate 1 avant implémentation.

**En tant que** propriétaire d'un document
**Je veux** le partager (en interne ou par lien public expirable) et conserver l'historique de ses versions
**Afin de** diffuser la bonne version tout en gardant une traçabilité

## Critères d'acceptation (outline — Gate 1 PO Agent)

| Critère | 🤖 Dev |
|---------|--------|
| Partage interne (rôle lecture / annotation) et partage par lien public (expirable, mot de passe optionnel) | ⬜ |
| Révocation d'un partage à tout moment | ⬜ |
| Chaque nouvel upload sur un document existant crée une version (auteur, date, taille) | ⬜ |
| Restauration d'une version antérieure | ⬜ |
| Sécurité : lien public accessible en lecture seule, jamais en modification | ⬜ |
